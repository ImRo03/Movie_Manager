# Movie Manager

A Python OOP project for managing a collection of movies.

## Features

- Add movies
- Display movies
- Search movies by title
- Filter movies by genre
- Find the highest-rated movie
- Remove movies
- Handle movies that are not found
- Handle an empty movie collection

## Concepts Used

- Classes and Objects
- `__init__`
- `self`
- Instance attributes and methods
- `__str__`
- Lists of objects
- Loops
- Conditional statements
- Basic edge-case handling

## How to Run

Open `Movie_Manager.ipynb` in Jupyter Notebook and run the cells.
